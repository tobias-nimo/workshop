# ML & Statistics Workshop

A personal collection of **machine learning** and **statistics** projects for learning and experimentation.

## Structure

```
workshop/
├── computer-vision/       # Image classification, object detection
├── nlp/                   # Text classification, text generation
├── multimodal/            # OCR, vision-language models
├── miscellaneous/         # Foundational ML concepts
└── statistics/            # Statistical analysis
```

## Requirements

Most projects use Python with common ML libraries:
- PyTorch / TensorFlow
- Transformers (Hugging Face)
- scikit-learn
- NumPy, Pandas, Matplotlib

See individual project folders for specific requirements.
